Collegamento a GitHub

Serve una volta sola su ogni telefono o computer. Il token resta salvato solo in questo browser.

  1. Su GitHub apri Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. In Repository access scegli Only select repositories e seleziona il repository dei dati.
  3. In Permissions → Repository permissions metti Contents su Read and write.
  4. Genera il token, copialo e incollalo qui sotto.
